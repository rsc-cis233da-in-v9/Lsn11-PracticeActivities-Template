Writing Directions and Modes

The following English phrase has been translated into different languages. It should be noted that Asian languages have multiple writing directions. Traditionally, they are written vertically and still do for certain things. However, over the years as they incorporated Western words and information, they have transitioned to also writing horizontally. In scenarios where Western languages and Asian languages are combined, the horizontal writing direction is utilized so users do not need to rotate the page to read different text.

Web development is a rewarding field.

Looks like this in Spanish: El desarrollo web es un campo gratificante.

Looks like this in German: Webentwicklung ist ein lohnendes Feld.

Looks like this in Chinese Simplified: 网络开发是一个有益的领域。

Looks like this in Japanese (because it incorporates a foreign Western word, it is written horizontally rather than vertically): Web 開発はやりがいのある分野です。

Looks like this in Hebrew:פיתוח אתרים הוא תחום מתגמל.
